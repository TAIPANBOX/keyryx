# keyryx v0.2.0

A minor release under 0.x, because the custody admin surface changes in a breaking way (see Upgrade). It also bounds the witness's memory on reads and adds committed statement vectors that a second verifier is held to.

Tag: `v0.2.0`. The image is `ghcr.io/taipanbox/keyryx:v0.2.0`. There is no moving tag (no `latest`, no `main`).

## Changed since v0.1.5

- #35, `feat(custody)!`: rotation and revocation are served only on the admin unix socket, `KEYRYX_DATA/admin.sock` (mode 0600, in the 0700 data directory, one request per connection), to a peer whose kernel-reported uid (SO_PEERCRED) is root or custody's own. The network route table no longer serves them. `KEYRYX_ADMIN_KEYS` is removed, and the start refuses when it is set to anything but empty. `keyryx admin rotate` and `keyryx admin revoke` are the commands.
- #35, bus announcements: every admin change is announced as `key_rotated` or `key_revoked` (SPEC 6.2 shapes), in order and at least once, into custody's own stream file, `KEYRYX_EVENTS` (required). The announcement is written only into a regular file that custody opens with O_NOFOLLOW, so a link planted on the shared bus cannot redirect it. Admin changes are serialized, and a change whose announcement did not queue is announced on the next run.
- #35, witness: a real producer's checkpoints, written by agent-stack-go's writer with a key that custody certified, are accepted end to end by the built witness, which raises a high finding on a rewrite (SPEC 6.5.1).
- #35, key ids: a key id that begins with an underscore or a hyphen is accepted.
- #36, `test(statement)`: committed statement vectors in `internal/statement/testdata/statement-vectors.json`. They hold the delegation root's key set and pin, two valid statements for checkpoint key names with their certified points, and nine variants a verifier must refuse (a missing half, a third signature, swapped halves, an altered signature, an edited payload, an unknown claim, another root). `TestTheStatementVectorsHold` checks the file on every run, so the heraldyx checkpoint gate verifies against the same bytes.
- #37, `fix(witness)`: a read's memory no longer grows with the stream. A read keeps only the lines the pending checkpoint records name (at most `MaxWanted` per interval), and answers records behind the read in one pass from byte zero. A line over `MaxLine` is hashed in pieces and never held in memory. A torn line is taken back out of the hash. A read raises at most `MaxRestartFindings` restart findings one by one, plus one more finding that counts the rest, high when any of the rest is unexplained. A witness reading a bus that was never rotated could previously grow past a 256 MiB limit.
- #39, `feat(custody)`: optional `KEYRYX_STATEMENTS_DIR`, off unless set. When set, custody keeps public copies in that directory for a reader on the same machine: `delegation-root.jwks.json` (the bytes the root JWKS endpoint serves) and `<kid>.json` (the statement and `revoked_at` for each delegated key). Writes are atomic, a revocation or root change is copied as part of the admin change (503 if the copy fails, and the change stands), and a failed copy is retried. The directory must be owned by custody's uid and writable by no one else, and custody refuses to start if it holds the root key file or the sockets. This lets heraldyx read custody's key statements from a file, with no network connection.
- #33, `deps`: agent-stack-go v2.0.3, built with Go 1.27.4.
- #32, documentation: the README, the compat status and `compat/1.0.json` name v0.1.5.

## Upgrade

1. The network admin key path is gone. Remove `KEYRYX_ADMIN_KEYS` from the environment, because the start refuses when it is set, and set `KEYRYX_EVENTS`, which is now required: custody refuses to start without it. Rotation and revocation are a CLI over the custody unix socket, served to root and to custody's own uid: `keyryx admin rotate` and `keyryx admin revoke`.
2. Custody announces `key_rotated` and `key_revoked` on the bus. These two event types are not yet in agent-passport SPEC 6.2 nor mapped by trailryx, so a record plane refuses them until those land.
3. Witness memory no longer grows with the stream, so no action is needed. To roll back, run v0.1.5 again; note that v0.1.5 still reads `KEYRYX_ADMIN_KEYS`.
