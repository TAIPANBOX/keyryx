# keyryx v0.1.5

A patch release on v0.1.4. The binary and the image are built with Go 1.27.4, which fixes GO-2026-6859 in `net/http`. The v0.1.4 image was built with Go 1.27.3. Nothing else changes in behaviour: no key, statement, log, route or variable moves.

Tag: `v0.1.5`. The image is `ghcr.io/taipanbox/keyryx:v0.1.5`. There is no moving tag (no `latest`, no `main`).

## Changed since v0.1.4

- #30, `build: Go 1.27.4 for GO-2026-6859`. The `toolchain` line in `go.mod`, the CI `go-version`, the teeth cases that plant faults next to the toolchain line, and the build image in the `Dockerfile` (the `golang:1.27.4` index, pinned by digest) move to Go 1.27.4. The runtime image is unchanged.
- #29, the actions in the workflows move to newer pinned commits.
- #28, documentation: the README, the distribution list and the compat status name v0.1.4.

## Upgrade

Pull `ghcr.io/taipanbox/keyryx:v0.1.5` and restart. No configuration, key store, policy or witness data changes. To roll back, run v0.1.4 again.
