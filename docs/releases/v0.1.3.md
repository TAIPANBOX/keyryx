# keyryx v0.1.3

A patch release on v0.1.2. The binary and the image are built with Go 1.27.3, which fixes GO-2026-6809 in `crypto/x509`. The v0.1.2 image was built with Go 1.27.2. The finding was reached through `tsa.Verify`, which calls `x509.Certificate.Verify` when an operator opts into time-stamping with `KEYRYX_WITNESS_TSA_URL`. Nothing else changes in behaviour: no key, no statement, no log, no route and no variable moves.

Tag: not yet tagged. There is no moving tag (no `latest`, no `main`).

## Changed since v0.1.2

- #20, `build: Go 1.27.3 for GO-2026-6809 in crypto/x509`. The `toolchain` line in `go.mod`, the CI `go-version`, the teeth cases that plant faults next to the toolchain line, and the build image in the `Dockerfile` (the `golang:1.27.3` index, pinned by digest) move to Go 1.27.3. The runtime image is unchanged.
- #19, `docs(readme): vouchryx consumes key statements and checks the ML-DSA half`. A README paragraph only; no code.

No other commit lies between the v0.1.2 tag and this release, apart from the post-tag documentation of v0.1.2 (#18).

## Upgrade

Pull `ghcr.io/taipanbox/keyryx:v0.1.3` and restart. No configuration, key store, policy or witness data changes.
